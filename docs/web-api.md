# Web API 接入

Web 直接请求现有 RSS 服务，不需要应用后端。运行 `pnpm dev` 后，在连接页填写服务地址和凭据。

## 连接方式

- **Miniflux**：填写部署根地址（可含子路径）和 API 密钥。例如本机环境为 `http://localhost:8880`。登录会请求 `/v1/me` 验证真实用户名，再读取分类、订阅和文章。
- **Google Reader 兼容**：填写协议入口的完整地址，例如 FreshRSS 的 `https://rss.example.com/api/greader.php`。使用 API 用户名和 API 密码换取令牌；不会保存密码。服务需要允许页面跨域访问，或与页面同源部署。
- **服务公开地址**：通过本机或局域网地址连接 Miniflux，且正文里的代理图片仍使用公开域名时，可填写服务器配置的公开地址。只映射该来源下的 `/proxy/` 路径，其他第三方图片地址保持原值。本机实例可填 `https://miniflux.chiyukiruon.top`。

未勾选“记住登录”时，凭据只保存在内存，刷新后需重新连接。勾选后沿用现有页面的 localStorage 保存 API 密钥或访问令牌；退出时清除凭据与内存文章。尚未迁移到设计草案规划的 IndexedDB。

支持保存多个 API 端点，可分别设置名称、服务地址、凭据和是否记住登录。在设置页添加和编辑端点；保存时会验证连接、读取订阅并切换到该端点。桌面端可在左下角或设置页切换，移动端在设置页切换。切换失败会保留原连接和文章；不同端点的图集、已读和收藏相互独立。旧版本保存的单个连接会自动迁移。

未记住的端点在刷新后移除，已记住的端点可在连接页再次选择。退出登录会清除全部端点及其保存的凭据；也可以在设置页单独删除未使用的端点。

## 已接入的行为

- 分类、订阅和文章来自服务器，真实连接不会混入演示数据。作者旁边显示订阅的分类（Miniflux 分类、Google Reader 标签），不按订阅地址猜测平台。
- Miniflux 通过 `before_entry_id` 连续分页，读取已读和未读文章；Google Reader 跟随 continuation 分页，同时补齐收藏流。ID 在模型里使用字符串，Google Reader 的 64 位 ID 不经过 Number 转换。
- 正文使用不挂载到页面的 template 解析，只输出文本和 HTTP(S) 图片。支持 img、picture/srcset、常见懒加载属性和图片附件；过滤明确的追踪像素并去重。
- 已读和收藏先更新界面，随后串行回写；请求失败时恢复最后确认的状态并提供重试。同步期间的新操作优先于旧快照；退出后迟到的响应不会重新写入当前账号。
- Miniflux 已读使用 `PUT /v1/entries`；兼容旧版的收藏操作先读取、必要时切换，再回读校验。Google Reader 使用写入令牌与 edit-tag 写入期望状态。
- 手动同步直接更新列表；回到前台的后台同步仅提示新文章数量，由用户决定何时显示。
- Miniflux 订阅刷新提交服务抓取请求，提示稍后同步。Google Reader 模式不展示不支持的手动抓取按钮。
- 图片下载实际 fetch 图片并保存 blob。无法读取时提示打开原图，用浏览器右键或长按保存；不按平台名称猜测下载能力。
- “下载成功后标为已读”默认开启，可在设置的“浏览”部分关闭。仅在本次下载的所有图片都成功读取并交给浏览器保存后标记所属图集；失败、部分成功、打开原图手动保存均不触发。浏览器不提供最终写入磁盘结果的通知。
- 移动端首页分类按钮自动换行，长分类名称也可换行显示。

## 验证结果

2026-10-15 使用本机 Miniflux 与无头 Edge，操作实际 Web 页面完成：

- 连接表单登录，读取 6 个订阅、120 篇文章，提取 174 张图片，未混入演示资源。
- 记住登录后刷新，重新同步文章，瀑布流渲染；进入订阅页、单个订阅与图集查看器。
- 验证 HTML 解析、懒加载、srcset、附件去重和追踪像素过滤。
- 单篇文章已读、收藏回写，远端回读确认，并恢复原始状态。
- 退出清除凭据和文章，再进入演示不会混入真实数据。

可重复运行（先启动本地 Miniflux 和 `pnpm dev`，需本机 Edge）：

```sh
node scripts/check-web-api.mjs
node scripts/check-web-api.mjs --allow-write
```

脚本从现有 Compose 文件读取账号，在内存中创建和使用临时 API Key，结束时删除 Key，不输出凭据。默认不改变文章状态；`--allow-write` 改动一篇文章的已读和收藏并恢复，但文章 changed_at 会前移。截图保存在忽略的 `.local-check/web-api.png`。

自动化测试另覆盖认证错误、分页停滞、子路径部署、Google Reader 字符串 ID 和写入参数，以及连续操作失败、同步与本地操作并发、退出后的迟到响应。

## 当前边界

- 本机 Google Reader 接口仍缺少跨域支持。适配器已通过协议模拟测试，尚未用真实 FreshRSS 完成浏览器联调；不能把接口兼容当成浏览器直连已验证。
- 当前每次同步会分批读取整个可用文章范围，全部成功后替换内存快照；大账号首次连接可能较慢。增量同步、按需历史回填、持久化文章缓存与离线操作队列待实现。
- 未提供可靠离线图片缓存，设置页已移除真实模式中的模拟缓存用量。下载是否可用取决于图片来源的网络、认证和 CORS 配置。
- 旧 Miniflux 收藏接口不支持原子“设为”操作，读后切换与回读只能提供尽力一致；其他客户端同时操作同一文章仍可能产生冲突。

接口依据：[Miniflux API](https://miniflux.app/docs/api.html)、[FreshRSS Google Reader API](https://freshrss.github.io/FreshRSS/en/developers/06_GoogleReader_API.html)。原有 API/CORS 与媒体验证见 [本地连接验证](local-connectivity.md)。
